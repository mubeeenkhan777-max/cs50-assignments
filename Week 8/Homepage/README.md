# CS50x Week 8 — Homepage

## Description

Homepage is a CS50x web development problem set in which I built a personal multi-page website using HTML, CSS, and JavaScript.

The website introduces my interests and goals in technology, particularly software engineering, cybersecurity, ethical hacking, and game development.

## Website Pages

### Home

The main landing page introduces my technology journey and interests.

### About Me

Provides information about me and the areas of computer science and programming that I am learning.

### Cybersecurity

Describes my interest in cybersecurity and ethical hacking, along with my learning goals.

### Game Development

Describes my interest in game development and my goals for learning game programming and creating games.

## Features

- Multiple interconnected webpages
- Navigation bar
- Responsive webpage structure
- CSS styling
- JavaScript interactions
- Interactive buttons
- Personal technology content

## Technologies Used

- HTML
- CSS
- JavaScript

## Files

- `index.html` — Homepage
- `about.html` — About Me page
- `cybersecurity.html` — Cybersecurity page
- `games.html` — Game Development page
- `styles.css` — Website styling
- `script.js` — JavaScript functionality

## Skills Practiced

This problem set gave me practical experience building a complete multi-page website and helped me understand how HTML, CSS, and JavaScript work together to create interactive web applications.
