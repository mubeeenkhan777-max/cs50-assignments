# CS50x Week 8 — Trivia

## Description

Trivia is a CS50x web development problem set that involves creating an interactive trivia webpage using HTML, CSS, and JavaScript.

The webpage allows users to answer both multiple-choice and free-response questions.

## Features

### Part 1 — Multiple Choice

The webpage contains:

- A trivia question
- Multiple answer buttons
- One correct answer
- Incorrect-answer feedback
- Correct-answer feedback
- Dynamic button colors

When an incorrect answer is selected, the button turns red and displays:

`Incorrect`

When the correct answer is selected, the button turns green and displays:

`Correct!`

### Part 2 — Free Response

The webpage also contains:

- A free-response question
- A text input field
- A confirmation button
- Correct and incorrect feedback
- Dynamic input-field colors

## Technologies Used

- HTML
- CSS
- JavaScript

## Skills Practiced

- HTML headings
- Buttons
- Input fields
- JavaScript functions
- Event handling
- DOM manipulation
- Dynamic styling
- User interaction

## Files

- `index.html` — Main webpage containing the trivia questions and JavaScript
- `styles.css` — CSS styling for the webpage
