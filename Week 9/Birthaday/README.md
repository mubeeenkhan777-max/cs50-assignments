# CS50x Week 9 - Birthdays

## Problem to Solve

A Flask web application that allows users to keep track of friends' birthdays.

## Description

This project is part of Harvard University's CS50x Week 9 problem set.

The application uses Flask, HTML, CSS, and SQLite to store and display birthday information.

Users can:

- View stored birthdays
- Add a person's name
- Add their birthday month
- Add their birthday day
- Store birthday information in a SQLite database
- View all saved birthdays in a table

## Technologies Used

- Python
- Flask
- SQLite
- SQL
- HTML
- CSS
- Jinja
