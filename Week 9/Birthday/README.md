
### 🎂 Birthday

**Birthday** is a Flask web application that allows users to:

* Add birthdays
* Store birthday information in a database
* View saved birthdays
* Edit or manage birthday data
* Work with HTML forms and Flask routes

**Main concepts used:**

* Flask
* Python
* HTML
* Jinja
* SQLite
* SQL
* Forms
* GET and POST requests

### 💰 Finance

**Finance** is a Flask web application that simulates buying and selling stocks.

Features include:

* User registration and login
* Checking stock prices
* Buying stocks
* Selling stocks
* Viewing portfolio
* Checking transaction history
* Adding cash
* Using sessions for logged-in users
* Storing user and transaction data in SQLite

**Main concepts used:**

* Flask
* Python
* SQL
* SQLite
* Jinja
* HTML
* CSS
* Sessions
* APIs
* Password hashing
* Database queries
