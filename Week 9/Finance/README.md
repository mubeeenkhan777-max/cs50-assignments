# CS50x 2026 — Finance 💰

This folder contains my solution for **Finance**, the Week 9 problem set of **CS50's Introduction to Computer Science (CS50x 2026)** by Harvard University.

## 📌 About the Project

**Finance** is a Flask-based web application that simulates a stock trading platform.

Users can register, log in, check stock prices, buy and sell stocks, and view their portfolio and transaction history.

## 🚀 Features

* 👤 User registration and login
* 🔐 Secure password hashing
* 💵 Check current stock prices
* 📈 Buy stocks
* 📉 Sell stocks
* 💰 View available cash
* 📊 View portfolio and stock holdings
* 🧾 View transaction history
* 🔄 Add additional cash
* 🗄️ Store information using SQLite
* 🔑 Use Flask sessions for authentication
