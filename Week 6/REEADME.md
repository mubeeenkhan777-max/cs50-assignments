# CS50x Week 6 – Python

This folder contains my solutions for **Week 6 of Harvard University's CS50x: Introduction to Computer Science**, where the focus shifts from C to **Python**.

* File handling
* CSV files
* Command-line arguments
* Exception handling
* String manipulation
* DNA sequence analysis

## Problem Sets

### Sentimental Mario – Less

A Python implementation of the half-pyramid problem from Problem Set 1.

### Sentimental Cash

A Python implementation of the Cash problem, calculating the minimum number of coins needed for a given amount of change.

### Sentimental Readability

A Python implementation of the Readability problem using the **Coleman-Liau index** to determine the grade level of a text.

### DNA

A program that identifies a person based on their DNA sequence by analyzing the longest consecutive occurrences of specific STRs and comparing the results with a DNA database.
