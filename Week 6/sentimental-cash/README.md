# Sentimental Cash

This folder contains my Python implementation of the **Cash** problem from CS50x.

## Description

The program asks the user how much change is owed in dollars and calculates the minimum number of coins needed to make that amount.

## Concepts Practiced

* Python input
* Variables
* Loops
* Conditionals
* Floating-point numbers
* Integer division
* Modulo operator
* Greedy algorithms
* Input validation
