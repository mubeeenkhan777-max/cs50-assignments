# Sentimental Readability

This folder contains my Python implementation of the **Readability** problem from CS50x.

## Description

The program asks the user to enter a piece of text and calculates its approximate U.S. grade level using the **Coleman-Liau index**.

The program analyzes the number of letters, words, and sentences in the provided text.

## Concepts Practiced

* String processing
* Loops
* Functions
* Conditional statements
* Character methods
* Mathematical calculations
* The Coleman-Liau readability formula
