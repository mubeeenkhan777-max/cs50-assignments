# Sentimental Mario – Less

This folder contains my Python implementation of the **Mario – Less** problem from CS50x.

## Description

The program asks the user for a height between 1 and 8 and prints a right-aligned half-pyramid using `#` characters.

## Concepts Practiced

* Python input
* `while` loops
* `for` loops
* Conditional statements
* Exception handling
* String multiplication
* Functions
