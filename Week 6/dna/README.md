# DNA

This folder contains my solution to the **DNA** problem from CS50x.

## Description

The program identifies a person based on their DNA sequence. It analyzes the longest consecutive repetitions of specific **Short Tandem Repeats (STRs)** and compares the resulting counts with a DNA database stored in a CSV file.

If all STR counts match a person in the database, the program prints that person's name. Otherwise, it prints `No match`.

## Key Function

The `longest_match()` function determines the longest consecutive occurrence of a specific STR within a DNA sequence.
