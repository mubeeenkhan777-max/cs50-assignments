# ⭐ Star Catching

## About the Project

This is my Week 0 project for **Harvard's CS50x: Introduction to Computer Science**.

**Star Catching** is a simple and fun game built using Scratch. The player controls a bowl to catch falling stars within a limited time while the game becomes more challenging as the stars fall faster.

## 🎮 How to Play

### Controls
- ⬅️ Left Arrow – Move the bowl to the left.
- ➡️ Right Arrow – Move the bowl to the right.

### Objective
Catch as many falling stars as possible within **30 seconds**.

- ⭐ Each caught star increases the score by **1**.
- ⚡ Every successful catch also increases the falling speed of the star, making the game more challenging.

### Game Over
- If a star falls past the bowl, it resets to the top of the screen.
- When the **30-second timer** reaches zero, the game ends and the final score is displayed.

## 💡 Programming Concepts Used

- Sprites
- Variables (Score, Timer, Speed)
- Loops
- Conditionals
- Random positioning
- Event-driven programming

## 📚 What I Learned

Through this project, I learned how to:
- Design a simple game using Scratch.
- Use variables to keep track of score and time.
- Apply loops and conditionals to control game logic.
- Increase game difficulty dynamically.
- Think like a programmer by solving problems step by step.
