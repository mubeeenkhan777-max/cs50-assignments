# CS50 Week 4 — Filter Less

## Description

This program applies different filters to BMP images by modifying the RGB values of individual pixels.

The implementation is completed in `helpers.c`.

## Filters Implemented

- **Grayscale** — Converts the image into shades of gray.
- **Sepia** — Gives the image a classic brownish/old-photo appearance.
- **Reflect** — Flips the image horizontally like a mirror.
- **Blur** — Applies a box blur by averaging the colors of neighboring pixels.

## Concepts Learned

- Structs
- RGB pixels
- Two-dimensional arrays
- Nested loops
- Image processing
- File handling
- Mathematical calculations
- Working with `RGBTRIPLE`

## File

- `helpers.c` — Contains the implementations of the four image filters.
