# CS50 Week 3 - Runoff

## Description

This program simulates an Instant Runoff (Ranked-Choice) election.

Voters rank candidates in order of preference. If no candidate receives a majority, the candidate with the fewest votes is eliminated and votes are transferred according to each voter's next preference until a winner is found.

## Features

- Records ranked votes.
- Tabulates votes.
- Eliminates candidates with the fewest votes.
- Transfers votes automatically.
- Detects ties.
- Declares the winner.
