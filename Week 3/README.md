# CS50 Week 3 - Algorithms

## Overview

Week 3 of Harvard's CS50 introduces fundamental algorithms and their applications in computer science. This week focuses on searching, sorting, algorithm efficiency, and implementing real-world voting systems in C.

Through these assignments, I learned how to analyze algorithms, compare their performance, and solve increasingly complex programming problems.

---

## Assignments

### 1. Sort
Analyzed three compiled sorting programs to determine which sorting algorithm they implement by comparing their performance on different datasets.

**Concepts Learned**
- Bubble Sort
- Selection Sort
- Merge Sort
- Time Complexity
- Algorithm Analysis

---

### 2. Plurality
Implemented a plurality voting system where each voter selects one candidate, and the candidate with the highest number of votes wins.

**Concepts Learned**
- Structs
- Arrays
- Functions
- Loops
- String Comparison (`strcmp`)
- Election Simulation

---

### 3. Runoff
Implemented an Instant Runoff (Ranked-Choice) voting system where voters rank candidates by preference. Candidates with the fewest votes are eliminated until a winner is determined.

**Concepts Learned**
- Two-Dimensional Arrays
- Structs
- Nested Loops
- Ranked-Choice Voting
- Algorithmic Problem Solving
- Election Simulation
