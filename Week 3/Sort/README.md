# CS50 Week 3 - Sort

## Description
This assignment analyzes three compiled sorting programs to determine which sorting algorithm they implement.

The algorithms studied are:

- Selection Sort
- Bubble Sort
- Merge Sort

The analysis was performed by comparing the running time of each program using random, sorted, and reversed datasets.

## Files

- `answers.txt` — Contains the identified sorting algorithms and explanations.

- Bubble Sort
- Selection Sort
- Merge Sort
