# Mario

This is my solution for the Harvard CS50x Week 1 **Mario (Less Comfortable)** problem.

## Description

The program prompts the user for the height of a pyramid and prints a right-aligned pyramid using hash (`#`) characters.

## Concepts Learned

- Variables
- Input validation using `do...while`
- Nested `for` loops
- Pattern printing
- Problem solving in C

Course: Harvard CS50x – Introduction to Computer Science
