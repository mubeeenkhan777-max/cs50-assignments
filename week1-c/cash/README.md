# Cash

This is my solution for the Harvard CS50x Week 1 **Cash** problem.

## Description

This program asks the user for the amount of change owed (in cents) and calculates the minimum number of U.S. coins required to make that amount.

The program uses the following coin denominations:
- Quarter (25¢)
- Dime (10¢)
- Nickel (5¢)
- Penny (1¢)

It uses a **greedy algorithm**, always choosing the largest possible coin first to minimize the total number of coins.

- `while` loops
