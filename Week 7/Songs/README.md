# CS50x Week 7 — Songs

## Description

Songs is a CS50x SQL problem set involving a SQLite database containing the 100 most-streamed songs on Spotify in 2018.

The goal was to write SQL queries to retrieve and analyze information about songs and artists.

## Concepts Practiced

- SELECT
- WHERE
- ORDER BY
- LIMIT
- AVG
- JOIN
- LIKE
- Filtering data
- Working with related tables

## Files

- `1.sql` — Lists all song names
- `2.sql` — Lists songs in increasing order of tempo
- `3.sql` — Finds the five longest songs
- `4.sql` — Finds songs with high danceability, energy, and valence
- `5.sql` — Calculates average energy
- `6.sql` — Finds songs by Post Malone
- `7.sql` — Calculates average energy of Drake's songs
- `8.sql` — Finds songs featuring other artists
- `answers.txt` — Contains reflections about Spotify's audio aura

## Database

`songs.db` is the SQLite database provided by CS50.

## Skills Learned

This problem set improved my understanding of SQL queries, filtering, sorting, aggregate functions, and relationships between database tables.
