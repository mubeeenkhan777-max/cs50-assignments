# CS50x Week 7 — Fiftyville

## Description

Fiftyville is a CS50x SQL mystery-solving problem set.

The CS50 Duck was stolen from the bakery on Humphrey Street. Using the information stored in a SQLite database, I investigated the available records to determine:

1. Who stole the duck
2. Where the thief escaped
3. Who helped the thief escape

## Investigation

The investigation involved analyzing several types of records:

- Crime scene reports
- Witness interviews
- Bakery security logs
- License plates
- ATM transactions
- Bank accounts
- Phone calls
- Flights
- Passengers
- Airports

## SQL Concepts Practiced

- SELECT
- WHERE
- JOIN
- IN
- LIKE
- ORDER BY
- LIMIT
- Filtering records
- Connecting information across multiple tables
- Logical investigation using database records

## Final Solution

- **Thief:** Bruce
- **Escape City:** New York City
- **Accomplice:** Robin

## Files

- `fiftyville.db` — SQLite database provided by CS50
- `log.sql` — SQL queries used during the investigation
- `answers.txt` — Final answers to the mystery

## Skills Learned

This problem set taught me how SQL can be used not only for retrieving data, but also for investigating and connecting information across multiple relational database tables to solve a real-world-style problem.
