# CS50x Week 7 — Movies

## Description

Movies is a CS50x SQL problem set based on an IMDb database containing information about movies, people, directors, actors, ratings, and release years.

The goal was to write SQL queries to answer questions about movies and the people involved in them.

## Concepts Practiced

- SELECT
- WHERE
- JOIN
- ORDER BY
- COUNT
- AVG
- LIKE
- LIMIT
- Subqueries
- Relational databases

## Files

- `1.sql` — Movies released in 2008
- `2.sql` — Birth year of Emma Stone
- `3.sql` — Movies released since 2018
- `4.sql` — Number of movies with a 10.0 rating
- `5.sql` — Harry Potter movies
- `6.sql` — Average rating of movies from 2012
- `7.sql` — Movies from 2010 ordered by rating
- `8.sql` — People who starred in Toy Story
- `9.sql` — People who starred in movies released in 2004
- `10.sql` — Directors of highly-rated movies
- `11.sql` — Highest-rated movies starring Chadwick Boseman
- `12.sql` — Movies starring Jennifer Lawrence and Bradley Cooper
- `13.sql` — People who starred with Kevin Bacon

## Database

`movies.db` is the SQLite database provided by CS50.

## Skills Learned

This problem set strengthened my ability to work with relational databases and combine information from multiple tables using SQL JOINs and subqueries.
