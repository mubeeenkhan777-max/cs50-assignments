# Dictionaries

This folder contains my work for the **Dictionaries** portion of CS50x Week 5.

## What I Learned

* How dictionaries can be represented using data structures
* How linked lists work
* How hash tables store and retrieve data
* How hash functions map words to buckets
* How dynamic memory allocation works with `malloc`
* How to properly free allocated memory with `free`
* How to search efficiently through a data structure

## Main Concepts

The dictionary implementation uses a **hash table** containing linked lists. Each word is converted into a hash value, which determines where the word is stored.

This helped me understand how data structures can make programs significantly more efficient.
