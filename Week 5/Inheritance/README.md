# Inheritance

This folder contains my solution for the **CS50x Week 5 – Inheritance** problem set.

## Problem Description

The Inheritance problem simulates how blood types are inherited from parents to children.

Each person has two blood type alleles, which can be:

* `A`
* `B`
* `O`

Each parent randomly passes one of their two alleles to their child.

## What I Learned

## Implementation

The program creates a family tree and randomly determines which blood-type alleles each child inherits from their parents.

It also uses dynamic memory allocation to create family members and properly frees the allocated memory after the simulation is complete.
