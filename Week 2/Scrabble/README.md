# Scrabble

## CS50 Week 2 – Scrabble

### Description
This program simulates a simple Scrabble game between two players.

The program:
- Prompts Player 1 to enter a word.
- Prompts Player 2 to enter a word.
- Calculates the Scrabble score for each word based on the official letter values.
- Compares both scores.
- Prints:
  - `Player 1 wins!`
  - `Player 2 wins!`
  - `Tie!`

### Concepts Practiced
- Functions
- Arrays
- Strings
- Loops
- Conditionals
- ASCII values
- `ctype.h` library (`toupper()`, `isalpha()`)
