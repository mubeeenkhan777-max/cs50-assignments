# Caesar

## CS50 Week 2 – Caesar

### Description
This program encrypts a message using Caesar's Cipher.

The program:
- Accepts a secret key as a command-line argument.
- Validates that the key is a positive integer.
- Prompts the user for plaintext.
- Encrypts each alphabetical character by shifting it according to the key.
- Preserves uppercase and lowercase letters.
- Leaves non-alphabetical characters unchanged.
- Prints the encrypted ciphertext.

### Concepts Practiced
- Command-line arguments (`argc` and `argv`)
- Strings
- Loops
- Conditionals
- ASCII values
- Modular arithmetic (`%`)
- `ctype.h`
- `stdlib.h`
- Caesar Cipher encryption
