# Readability

## CS50 Week 2 – Readability

### Description
This program calculates the readability grade level of a piece of text using the Coleman–Liau Index.

The program:
- Prompts the user for a block of text.
- Counts the number of letters, words, and sentences.
- Calculates the Coleman–Liau Index.
- Prints:
  - `Before Grade 1`
  - `Grade X`
  - `Grade 16+`

### Concepts Practiced
- Strings
- Loops
- Conditionals
- Functions
- `ctype.h`
- `string.h`
- `math.h`
- Floating-point calculations
- Coleman–Liau readability formula
